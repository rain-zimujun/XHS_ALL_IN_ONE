# grillme —— 苏格拉底式追问

> 来源：https://github.com/Jekudy/grillme-skill （`skills/grillme/SKILL.md`）
> 用途：在动手实现之前，用多轮提问把方案里的隐藏假设、风险和未定义行为挖出来。
> 说明：本文件是项目内的副本，DSH 的技能目录无法由 agent 注册；需要时直接按本文件执行。

## 使用方式

用户说「grillme」「追问我」「审一下这个方案」「帮我查缺」时启用：

1. 判断领域（产品/架构/个人决策/规划/调研），选 3～4 个分析镜头；
2. 分波提问：第一波打基础（目标、上下文、约束），第二波挖边角（异常、冲突、依赖），第三波挖矛盾（隐含假设、未覆盖场景）；
3. 每波之间给小结：**已确认的事实 / 未验证的假设 / 风险 → 下一波的问题**；
4. 找到张力就跳出现有提纲，追着那条线问；
5. 结束前确认「是否还有没覆盖的点」，然后给最终汇总（事实、决策、假设、风险与缓解、开放问题、下一步）。

## 分析镜头（挑 2～3 个）

| 类别 | 镜头 | 提问方式 |
|---|---|---|
| 战略 | 负面空间 | 「你没提 X，是刻意不做还是没想到？」 |
| 战略 | 相关方 | 「这会影响到谁？他们知道吗？」 |
| 战略 | 被否决的备选 | 「考虑过 Y 吗？为什么放弃？」 |
| 战略 | 机会成本 | 「做这个的代价是暂时不做哪个？」 |
| 战略 | 确定度 | 「这是验证过的事实，还是感觉？」 |
| 系统 | 依赖 | 「如果 X 不成立，还有什么会塌？」 |
| 系统 | 二阶效应 | 「这会导致 B，B 又会导致什么？」 |
| 系统 | 时间尺度冲突 | 「三个月后这个决定还成立吗？」 |
| 心理 | 谁想要 | 「如果没人知道结果，你还会做吗？」 |
| 心理 | 回避 | 「刚才这个问题你答得很快，里面难的地方是什么？」 |
| 挑战 | Pre-mortem | 「半年后这事失败了，最可能的原因是什么？」 |
| 挑战 | 反向 | 「要让它一定失败，你会怎么做？」 |
| 挑战 | 停止条件 | 「出现什么结果你就认输？」 |
| 挑战 | 最小版本 | 「只解决 80% 的最小版本长什么样？」 |
| 挑战 | 追问为什么 | 「你要 X，为什么是 X？X 背后是什么？」 |

## 常见错误

- 只问一轮就收工（真正的信息在第二、三轮）；
- 一次抛出四五个问题（失去追问的连贯性）；
- 问题太抽象，没有具体选项；
- 只顾覆盖类别，不去追已经露出的矛盾；
- 只问安全的问题，不碰 pre-mortem 和反向问题；
- 把风险列成清单却不转成下一轮的问题；
- 最后不确认覆盖就下结论。
