# 热点创作改造任务清单

开发分支：`feat/ai-fashion-daily-report`。

项目长期变更档案见 [`docs/project-change-log.md`](project-change-log.md)，每个小任务完成后同步更新。

用户流程：绑定小红书 PC 账号 → 输入关键词 → 选择排序、时间、类型与 20/30/50 篇 → 预览勾选 → 采集完整正文 → AI 综合分析 → 获取原创标题、正文、配图说明与生图提示词 → 自行配图发布。

## 交付规则

- 每个编号任务完成后检查、独立提交，再推送到个人 Fork 的同名分支。
- 提交信息使用英文 Conventional Commits 类型前缀，后接中文说明，例如 `feat: 新增读者需求分析 Agent`、`fix: 修复模型超时处理`、`docs: 更新项目改造档案`。已有历史提交不改写。
- 沿用原有账号与模型配置；新流程不调用发布接口、不自动生图。
- 搜索与采集数量据实显示；样本不足、登录失效、模型失败都有明确状态。
- 真实账号与模型调用需要用户完成配置；离线测试使用隔离数据库和模拟服务。
- 不提交 Cookie、密钥、本地数据库、依赖目录和生成报告。

## A. 手动流程（先验证内容质量）

- [x] A0：本地启动基线。依赖安装，前端构建，130 项原有后端测试通过；仅监听本机，关闭后台定时任务。
- [x] A1：搜索与选取。新增“热点创作”入口、PC 账号选择、关键词、综合/最新/点赞/收藏/评论排序、时间和类型筛选、20/30/50 篇、自动翻页去重、结果勾选与来源链接。
  - 验收：多个搜索页准确合并，数量不会超过上限；不足数量明确提示；新搜索不混入旧结果；仅能使用自己的账号。
- [x] A2：批量正文采集。仅抓取选中的笔记，后台运行并保存进度、成功样本及失败记录；刷新页面后可找回任务；支持停止。
  - 验收：部分失败仍保留成功样本；登录失效停止；不下载原图或自动发布；后台请求不会因为前端超时而丢失结果。
- [x] A3：AI 综合策划。选择文字模型、目标受众及创作要求，生成 1/3/5 个标题，每个标题对应 2/3 版正文与配图；输出结构化校验与来源核验。
  - 验收：每个标题包含不同文案版本，每版有正文、标签、封面文字、配图脚本和提示词，标题级有推荐理由与参考笔记；综合本批样本的表达风格，不把单篇改写当作多样本趋势，不虚构亲测体验或增长率。
- [x] A4：结果展示与报告。展示分析摘要、可复制内容卡、来源和历史任务；生成 HTML 与 JSON（含采集数据）报告。
  - 验收：失败状态可见；导出内容与页面一致；不同用户不可访问彼此报告；报告文本安全转义；输出位置清晰。
- [x] A5.1：自动化验收。后端单元/接口测试、前端构建和模拟浏览器流程测试；补齐翻页会话一致性、后续页失败保留结果、任务中心防止错误重试和历史参数回显。
- [ ] A5.2：真实验收。用户用自己的小红书账号与文字模型验证真实结果，按 `docs/hot-content-guide.md` 的清单验收；真实验收后再校准生成质量。
