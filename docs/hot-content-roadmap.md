# 热点创作改造任务清单

默认开发与交付分支：个人 Fork `rain-zimujun/XHS_ALL_IN_ONE` 的 `master`。原 `feat/ai-fashion-daily-report` 分支保留，后续默认不再作为交付目标。

项目长期变更档案见 [`docs/project-change-log.md`](project-change-log.md)，每个小任务完成后同步更新。

用户流程：绑定小红书 PC 账号 → 输入关键词 → 选择排序、时间、类型与 20/30/50 篇 → 预览勾选 → 采集完整正文 → AI 综合分析 → 获取原创标题、正文、配图说明与生图提示词 → 自行配图发布。

## 交付规则

- 每个编号任务完成后检查、独立提交，再推送到个人 Fork 的 `origin/master`；除非用户另行指定，不新建开发分支，不向原作者的 `upstream` 推送。
- 提交信息使用英文 Conventional Commits 类型前缀，后接中文说明，例如 `feat: 新增读者需求分析 Agent`、`fix: 修复模型超时处理`、`docs: 更新项目改造档案`。已有历史提交不改写。
- 沿用原有账号与模型配置；新流程不调用发布接口、不自动生图。
- 搜索与采集数量据实显示；样本不足、登录失效、模型失败都有明确状态。
- 真实账号与模型调用需要用户完成配置；离线测试使用隔离数据库和模拟服务。
- 不提交 Cookie、密钥、本地数据库、依赖目录和生成报告。
